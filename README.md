# 🚨 Emergency Sign Detection

This project detects emergency hand signs using Deep Learning (CNN) and OpenCV.

## 🔍 Features
- Real-time webcam detection
- 8 emergency signs
- Confidence-based prediction ("Confused" handling)

## 🧠 Technologies Used
- Python
- TensorFlow / Keras
- OpenCV

## ▶️ How to Run

1. Install dependencies:
pip install -r requirements.txt

2. Train model:
python emergency_sign_detection.py

3. Run detection:
python detect_emergency_sign.py

## 📂 Classes
accident, call, doctor, help, hot, lose, pain, thief
